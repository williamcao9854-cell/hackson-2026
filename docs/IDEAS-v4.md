# 创意方案 v4：小而美，给普通人的日常

> 前几版的问题：我把赛道一理解窄了，只想着"帮助弱势群体"，结果方向都很沉重、很像公益提案。
> 赛道原文是 **"improve everyday life through human care, inclusive experiences and genuine user needs"**。**普通人日常生活里的真实需求**同样符合要求。
>
> 这一版先调研了近两年 Apple 获奖的小众精品 App，提炼出它们的共同点，再根据这些共同点想方向。

---

## 一、调研：小众精品为什么让人"忍不住打开"

| App | 获奖 | 它做了什么 |
|---|---|---|
| **CapWords** | 2025 Apple 设计大奖·趣味类 | 拍下身边任何物品，变成一张**贴纸**，同时告诉你它的外语单词。北京 3 人团队，**没有服务器**，照片识别完就删 |
| **Tiimo** | 2025 年度 iPhone App | 把拥挤的日历变成平静、按颜色区分的视觉时间线 |
| **Focus Friend** | 2025 App Store 文化影响奖 | 你专注的时候，一颗小豆子在旁边织毛线 |
| **Moonlitt** | 2026 Apple 设计大奖·交互类 | 只做一件事：看月相 |
| **Tide Guide** | 2026 Apple 设计大奖·视觉类 | 只做一件事：看潮汐 |
| **Hanafuda Tactics** | 2025 Swift 学生挑战赛获奖 | 让年轻人重新学会一种日本传统纸牌游戏 |
| **小停顿** | App Store 推荐 | 用插画记录"治愈小事"，点一下 +1 |

### 它们的共同点
1. **把日常变成收藏**：CapWords 把随手拍的东西变成贴纸，收集欲会推着你一直用下去
2. **一件小事，做到极致**：月相、潮汐、专注，主题都很小
3. **可爱的陪伴感**：一颗织毛线的豆子，比任何"专注时长统计"都更让人想打开
4. **有文化，有温度**：传统游戏、自然节律，不只是工具
5. **隐私优先、设备端**：CapWords 没有服务器，这也是 Apple 最看重的价值

👉 **新方向的标准**：小而美 + 有收藏感 + 有文化温度 + 图像生成是魔法本身 + Core ML 真的有用

## 二、5 个新方向

### 1. 「物灵」：给旧物一场告别仪式 ⭐

**一句话**
拍下一件要扔掉的旧物，AI 画出它的"**物灵**"（它的灵魂形象）。你写一句告别的话，然后安心放手。所有物灵收进你的「物灵图鉴」。

**灵感**
- 日本民间传说**付丧神**：器物用久了会生出灵魂
- 日本至今还有真实的**人形供养、针供养**：扔掉玩偶、旧针之前，要先办一场感谢仪式
- 断舍离的核心步骤之一，就是"**扔之前，先谢谢它**"

**真实需求**
- 毕业、搬家、换季整理时，很多人**舍不得扔**："这双鞋陪我跑完了第一个半马""这是高中同桌送的杯子"
- 结果就是东西越堆越多。真正让人舍不得的不是东西本身，而是**东西背后的记忆**
- 👉 **把记忆留下，把东西放下**

**魔法时刻**
你拍下一双磨破的跑鞋。几秒后，它变成一个**伤痕累累但神采奕奕的小战士**，鞋底的每道磨痕都是它的勋章。你写下："谢谢你陪我跑完 1000 公里。"点击「送别」，物灵化作光点飞进图鉴。

**Core ML 的作用**
设备端识别物品类别（鞋、杯子、玩偶、书），再结合识别到的磨损程度、颜色，决定物灵的性格和样子：用得越久，物灵越"老练"

**图像生成**：⭐⭐⭐ 物灵就是生成出来的，没有它就没有这个产品

**为什么"忍不住用"**：收集欲（图鉴）+ 仪式感 + 可以分享（"看看我的旧手机变成了什么"）

### 2. 「手影剧场」：用手影和孩子一起讲睡前故事 ⭐

**一句话**
在手机摄像头前比一只手影兔子，屏幕上的绘本里就**跳出一只兔子**。爸妈和孩子用手影一起"演"出今晚的睡前故事。

**灵感**
- 手影戏是很多人童年的回忆，墙上的一只狗、一只鸟，但这门**老手艺正在消失**
- 和 Hanafuda Tactics 一样，这是在**让传统游戏回到年轻家庭**

**真实需求**
- 父母想和孩子有高质量的睡前时光，但往往只能"念书"或者"给手机"
- 👉 手影让孩子**动起来、参与进来**，故事每晚都不一样，而且是两个人一起创作的

**魔法时刻**（路演现场可以演示）
评委对着摄像头比出一只兔子，屏幕上的绘本场景里马上出现一只插画兔子。再换成老鹰，老鹰飞进来，故事接着往下讲。

**Core ML 的作用（分量最重的一个）**
用 **Create ML 的手势分类模板**，训练一个识别手影造型（狗、兔子、老鹰、蜗牛、鹿）的模型，靠 Vision 的手部关键点检测在设备端实时运行。这是**我们自己训练的模型**，评委会很认可

**图像生成**：⭐⭐⭐ 每个角色都会融入当晚的故事场景，每晚都不一样

**设计亮点**
睡前模式：暖色、低亮度、大画面，像一本会动的绘本，而不是又一块刺眼的屏幕

---

### 3. 「散步长卷」：把你的城市漫步画成一幅长卷

**一句话**
散步时随手拍几张（一只猫、一棵银杏、一杯咖啡），回家后 App 把你的路线画成一幅**长卷**：路线是河流，你遇到的东西都是画里的小景。

**灵感**
- 年轻人中流行 **Citywalk**
- 中国传统长卷（比如《清明上河图》）本来就是"**边走边看**"的一种画法

**真实需求**
走路的时候低头刷手机，走完就忘了。这个 App 让人**抬头看身边的东西**，因为每一个发现都会进入你的画卷

**魔法时刻**
走完回家，打开 App，一幅长卷**徐徐展开**，你今天遇到的那只橘猫，就趴在画里的屋檐上

**Core ML 的作用**
设备端识别你拍的东西（猫、树、咖啡、自行车），转成画中元素；MapKit + 计步器记录路线和步数

**图像生成**：⭐⭐⭐

**彩蛋**：你们现在正在散步，路演开场可以说"这个点子就是在散步时想到的"

---

### 4. 「云中有物」：拍一朵云，看看它像什么

**一句话**
拍下天上的云，Core ML 告诉你这是积云还是卷云，AI 再把**云里藏着的动物**画出来。

**灵感**
- 英国有一个真实的**赏云协会**（Cloud Appreciation Society），会员遍布全球
- 小时候躺在草地上说"那朵云像一只鲸鱼"，这种乐趣，长大以后就没了

**真实需求**
一天到晚低头看屏幕。这个 App 的唯一目的，就是让你**抬头看天**

**Core ML 的作用**
设备端云型分类（积云、卷云、层云……），可以用 Create ML 训练

**图像生成**：⭐⭐⭐ 但**需要"以图生图"**，要看 AMD API 支不支持

**风险**：如果 API 只支持文字生成图片，这个方案就做不成

---

### 5. 「冰箱住客」：冰箱里的每样食物，都是一个快过期会着急的小精灵

**一句话**
拍一下冰箱，Core ML 识别出鸡蛋、西兰花、牛奶，每样食物变成一个小精灵。快过期的时候，它会越来越着急，**等你来"救"它**（做成菜）。

**真实需求**
一个人住的年轻人经常买多了吃不完，过几天就扔掉，又浪费又愧疚

**Core ML 的作用**：设备端识别食物种类

**图像生成**：⭐⭐ 小精灵可以生成，但其实提前做好一套形象也行，必要性偏弱

## 四、我的推荐

**「物灵」和「手影剧场」二选一：**

- **想要故事打动人 → 物灵**
  概念最原创，"把记忆留下，把东西放下"这句话就能撑起整场路演，图鉴的收集感也很像 CapWords
- **想要现场效果炸 → 手影剧场**
  评委亲手比一只兔子，兔子就跳进绘本，这种互动别的队很难做出来。而且有**自己训练的 Core ML 模型**，技术含量最实在
