## 一、设计调研：向谁学

| 参考 | 学什么 |
|---|---|
| **Apple HIG · Liquid Glass（iOS 26/27）** | 玻璃只用于**控制层**（按钮、工具栏），内容层保持实体。我们的内容是"纸"，控制是"玻璃" |
| **Apple 照片 App · 主体抠图（Visual Look Up）** | 长按主体会被"拎起来"，边缘有一圈流光。这是 iOS 用户最熟悉的魔法，我们直接复用它的动效语言 |
| **Apple 日记 App（Journal）** | 克制的排版、大留白、卡片式回忆。物灵图鉴的气质参考它 |
| **CapWords（2025 Apple 设计大奖）** | ① 拍照 → 贴纸，即时满足感 ② 等待 AI 时用**微动画**填满，让人感觉不到在等 ③ 照片用完即删，隐私优先 |
| **Focus Friend / Tiimo** | 情绪化的陪伴感，以及柔和、克制的配色 |
| **日本「人形供养」「针供养」** | 送别仪式的结构：感谢 → 告别 → 封存。长按送别的交互就源于此 |

## 二、设计语言：「和纸与朱印」

### 原则
1. **安静**：一屏只做一件事，大留白，没有多余装饰
2. **实体与玻璃**：内容像纸一样有质感，控制像玻璃一样轻
3. **仪式感来自节奏，不来自特效**：慢下来的动画、逐渐增强的触感，比满屏粒子更有分量
4. **一点朱红**：全 App 只有一种强调色，用在印章和主按钮上

### 颜色

| Token | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `paper` | `#F4F0E8` 和纸白 | `#15130F` 墨夜 | 背景 |
| `card` | `#FBF8F2` | `#1F1C17` | 卡片 |
| `ink` | `#1C1A17` | `#EDE8DF` | 主文字 |
| `inkSecondary` | `#7A746B` | `#9A9388` | 次要文字 |
| `vermilion` | `#C8442F` 朱 | `#E0583F` | 印章、主按钮，**唯一强调色** |
| `hairline` | `#1C1A17` 10% | `#EDE8DF` 12% | 分隔线 |

### 字体
- 中文：系统 **苹方**，标题用 Semibold，正文用 Regular
- 西文和数字：标题用 **New York**（Apple 系统衬线体），编号、日期用等宽数字。例如 `No. 012`、`2026.11.21`
- **物灵名字竖排**，像挂轴上的题字，这是整个 App 最有辨识度的元素

### 物灵画风（所有生成图共用一套提示词模板）
> 水彩与墨线的付丧神插画，和纸质感的暖白背景，低饱和的大地色系，只点缀一抹朱红，角色居中、全身，大量留白，灵动又有尊严，无文字

生成图的背景色与 App 的 `paper` 色一致，**插画会自然融进页面**，不会有"贴上去的图片"那种割裂感。

### 动效与触感
- **抠图拎起**：主体从照片中浮起，边缘一圈流光扫过，配合 `.sensoryFeedback(.impact)`
- **唤醒等待**：贴纸缓慢呼吸、轻微漂浮，下方一行字依次切换（"它记得你……"），时间被氛围填满
- **初见**：纸面从中间展开，物灵淡入，名字逐字竖排写出
- **送别**：长按 3 秒，进度环沿印章外圈走一周，触感由弱到强；松手时原物照片化作光点消散，朱印「已送别」盖下，配一次 `.success` 触感
- 图鉴进入详情使用系统的 **zoom 转场**（`navigationTransition(.zoom)`）

## 三、信息架构

```
图鉴（首页）
 ├─ 同住：还留在身边的物灵
 ├─ 已送别：送走了，记忆还在
 ├─ 物灵详情：大图、竖排名字、它的故事、原貌 ⇄ 灵貌切换、分享卡片
 └─ [遇见] 悬浮玻璃按钮
       ↓
遇见流程（全屏）
 ① 取景：自制相机 / 相册
 ② 拎起：Vision 抠出主体 → Core ML 识别它是什么
 ③ 讲讲它：陪了你多久？（选项）一段关于它的记忆（可选）
 ④ 唤醒：生成物灵（AMD API）+ 起名（设备端）
 ⑤ 初见：物灵卡揭晓
 ⑥ 选择：送别（仪式）或 留下（同住）
```

## 四、技术方案

| 模块 | 技术 | 说明 |
|---|---|---|
| 界面 | SwiftUI · iOS 26+ | 原生 Liquid Glass |
| 数据 | SwiftData | 图片以外部存储方式保存 |
| 抠图 | Vision `VNGenerateForegroundInstanceMaskRequest` | 设备端，和照片 App 同款能力 |
| **物品识别** | **Core ML · MobileNetV2**（Apple 官方模型）+ `VNCoreMLRequest` | 设备端；英文标签对照成中文，用户可以修改 |
| 物灵配色 | Core Graphics 提取主色 | 用主色指导生成，物灵会"长得像"原物 |
| 起名与性格 | **Foundation Models**（Apple 设备端大模型），不可用时退回模板 | 设备端生成名字、称号和一句性格描述 |
| **物灵生成** | **AMD 图像生成 API** | 兼容 OpenAI 的 `/images/generations` 格式，地址、模型、Key 都可以配置 |
| 无网络演示 | 本地占位生成器 | 没有 Key 也能完整跑通流程 |
| 相机 | AVFoundation 自制取景器 | 比系统相机界面更贴合设计 |
| 分享 | `ImageRenderer` + `ShareLink` | 导出一张精美的物灵卡片 |

### 隐私
- 抠图、识别、起名**全部在设备端完成**
- 只有一段**文字描述**（物品类别 + 颜色 + 陪伴时长）发给图像 API，**原照片不上传**
- 路演可以讲：这一点和 CapWords 的理念一致

### 工程
- Xcode 项目使用**文件夹同步**（Xcode 16+），新加的文件自动纳入项目，多人协作不会在 `project.pbxproj` 上冲突
- 另外附一份 XcodeGen 的 `project.yml` 作为备用
- API Key 放在 `Secrets.plist` 里，**已加入 .gitignore**，不会提交到公开仓库

## 六、风险

| 风险 | 应对 |
|---|---|
| 开发机是 Linux，没法编译 iOS | 在 Linux 上装了 Swift 6.4 做语法检查；纯逻辑代码做完整类型检查；Swift 代码由 Mac 那边编译验证 |
| 手写的 Xcode 项目文件可能打不开 | 备用方案 1：XcodeGen；备用方案 2：新建空项目，把 `Wuling/` 文件夹拖进去 |
| AMD API 格式未知 | 生成服务做成可替换的接口，先按 OpenAI 兼容格式实现，拿到文档后只需要改配置或一个文件 |
| 需要 iOS 26 | Xcode 26/27 都支持；真机需要 iOS 26 及以上 |
| Foundation Models 只在支持 Apple 智能的设备上可用 | 自动退回模板起名，功能不受影响 |

## 七、v1.1「传灵」：回应评审意见

### 收到的意见（GPT 评审）
1. 用户体验一次之后，**第二次打开的动力不够**
2. "输入 → 等待 → 出图"是 AI 应用的老套路
3. 建议方向：No Camera / Undo IRL / Relay（物品接力）

### 我们的判断
- 1、2 两点**认同**
- **No Camera** 本质上就是之前否掉的"声音明信片"（环境声生成抽象图），同样存在"生成图不承载真实记忆"的问题，而且需要额外开发 Watch 端
- **Undo IRL** 演示直接，但和"人文关怀"赛道关系弱，多物体配准的技术风险高，AMD API 也只能用在海报上
- **Relay 是对的方向，但它应该是物灵的下一步，而不是另起炉灶**

### 设计：送别有两种
| | 送别（放手） | **传灵（送给下一个人）** |
|---|---|---|
| 物品去向 | 扔掉、回收 | 送给朋友、学弟学妹、二手转让 |
| 物灵去向 | 留在我的图鉴 | **带着故事，跟物品一起走** |
| 仪式 | 长按印章，原物化作光点 | 盖上我的名章，隔空投送 |

### 核心灵感：鉴藏印
《清明上河图》上盖满了历代收藏者的印章，每一枚都在说："它曾经属于我。"
物灵也一样：**每经过一位主人，就多一枚他的名章。** 名章交替使用白文（红底白字）和朱文（白底红字），层层叠叠，就像古画上的鉴藏印。

### 它解决了什么
- **第二次打开**：收到别人传来的物灵；或者把同住的物灵传出去
- **第二个用户**：每一次传递，都会把物灵带给一个新用户
- **10 秒演示**：两部手机，A 盖章投送，B 打开就看到上一任主人的名章和留言，再盖上自己的
- **不需要服务器**：`.wuling` 文件通过隔空投送传递，Apple 原生
- **可持续消费**：毕业季、二手交换时，东西送出去了，故事也跟着过去

### 隐私
- 要不要附上自己的那段记忆，由传出的人决定（默认附上，可以关掉）
- 接收的人只看到名章、日期、留言和对方愿意分享的记忆

### 路演演示脚本（两部手机）
1. **手机 A**：拍下一把旧吉他 → 唤醒物灵「青弦丸」→ 留它同住
2. A 打开详情 → **传给下一位** → 名章写"小林"，留言"它怕潮，下雨天别带它出门" → **盖上名章**（印章落下，咚的一下震动）→ 隔空投送
3. **手机 B**：收到物灵，弹出「一个物灵来到了你身边」→ 看到小林的名章和留言 → 写下自己的名章"阿明"→ **盖章，收下它**
4. 卡片上出现两枚错落的印章：「第 2 代主人」

## 八、v1.2 根据 Gemini 代码审查的修复

| 问题 | 修复 |
|---|---|
| 用户改了物品名（如"外婆的闹钟"），生成时仍用识别出的旧类别 | 从改后的名字里反查物品类别；提示词里带上用户的称呼 |
| 离线起名完全没用到用户写的记忆 | 性格描述里摘录记忆的第一句："它一直记得：「……」" |
| 生成的物灵和原物长得不像 | 新增「岁月留下的痕迹」多选（褪色、掉漆、贴满贴纸……），写进提示词 |
| Core ML 中心裁剪，长条物体被切掉头尾 | 主体补成正方形白底，改用缩放而不是裁剪 |
| 识别不了耳机、保温杯、钥匙等常见物品 | 同时使用 Core ML 和 Vision 内置分类器；补充常见物品；给出「是不是：××」候选一键改正 |
| 详情页进入送别后退不出来 | 加关闭按钮 |
| 拍歪了不能重拍 | 「讲讲它」页加重拍按钮 |
| 初见页点 × 直接丢掉刚生成的物灵 | 关闭前确认，可以选择"留它同住" |
| 深色模式下插画上的名字看不见 | 压在插画上的文字固定使用深墨色 |
| 玻璃按钮 `.tint` 可能把玻璃染成灰黑 | 改为只设置文字颜色 |
| 快门连点会出问题 | 拍照中禁用快门；相机层也做了防重入 |
| `.wuling` 文件太大 | 插画转 JPEG、限制尺寸，从几 MB 降到几百 KB |
| 发送后要手动点"已经传出去了" | 改用系统分享面板，发送成功自动标记 |
| 盖章后输入框锁死 | 可以"重新填写" |
| 接收方显示"相伴几天 · 遇见于今天" | 改为"接过于 · 第几代主人" |
| 筛选把"已传出"算进"已送别" | 拆成 全部 / 同住 / 已送别 / 已传出 |
| 删除记录后编号撞号 | 编号改为"现有最大编号 + 1" |
| 正在遇见时收到物灵，弹窗被吞掉 | 先关闭遇见，等退场后再弹出 |
| 每次进详情都同步渲染分享图，拖慢转场 | 延迟到转场结束后渲染 |
| 日式付丧神与中式鉴藏印的文化缝合感 | 统一为"东方惜物"叙事，以《抱朴子》「万物之老者，其精悉能假托人形」为本土出处；名字结尾改为 君/子/生/郎/儿；去掉 TSUKUMOGAMI 字样 |
| 按钮写死"隔空投送" | 改为"传给下一位"，隔空投送、微信、信息都能用 |
| README 把 AMD API 写成"可选" | 改为"比赛必须"，并附海报生成脚本 |

## 九、v1.3 真机试用后的改进

### 1. 名字不限长度
- 名章不再限制 1～4 个字。字多时印章自动分列（3～4 字每列 2 字，更多时排成近似方形）；西文名字横排并自动缩小
- 物灵的名字可以自己改：初见页轻点名字，或在详情页菜单里「改名」。名字太长时竖排自动分成几列，从右往左

### 2. 识别更准
| 改进 | 说明 |
|---|---|
| 换模型 | MobileNetV2（ImageNet 约 71%）→ Apple 官方 **FastViT-MA36**（约 84%） |
| 两张图 | 抠出的主体 + 整张照片各识别一次，整张照片提供上下文 |
| 两个模型加权合并 | Core ML 与 Vision 内置分类器的结果按权重相加，多个来源都认同的物品排在前面 |
| 同义词取最具体的 | ImageNet 的 "notebook, notebook computer" 不再被认成纸质笔记本 |
| 没把握就问 | 合并后的置信度不够时，名字留空，提示"我没认出来，告诉我它是什么吧"，并给出候选或常见选项 |

> 识别的根本局限在于：ImageNet 只有 1000 类，很多生活物品不在里面。所以"没把握就问"比"硬猜"更重要：认错一个名字，比问一句更破坏信任感。

### 3. 会呼吸的园林
参考：Apple **天气** App 的动态背景、《**妙笔千山**》与《千里江山图》的青绿山水、《**阿尔托的奥德赛**》（Alto's Odyssey）的昼夜与天气。

| 元素 | 设计 |
|---|---|
| 山 | 三层远近山峦，远淡近浓，山脚化入雾中留白；白天褪色青绿，秋偏赭，冬偏灰并有积雪 |
| 时辰 | 清晨、白天、黄昏（朱红夕阳）、夜（墨色天空、月亮、星）；深色模式固定为夜景 |
| 节气 | 按太阳视黄经实时计算二十四节气，竖排显示节气与七十二候，如「立冬 · 水始冰」 |
| 季节 | 冬雪、春花瓣、秋银杏叶、夏夜萤火 |
| 园林 | 左上角柳枝垂下随风轻摆；山间流雾；水面涟漪与日月倒影 |
| **Liquid Glass 月洞门** | 日月前悬一片圆形透明玻璃，像透过园林的月洞门看景，玻璃折射后面的山水 |
| 景深 | 倾斜手机，远山、近山、柳枝按层次错动 |
| **映出你的图鉴** | 每送别一个物灵，水面多一盏**河灯**；每传出一个物灵，远天多一只**鸿雁**（鸿雁传书） |
| 无障碍 | 开启"减弱动态效果"时，画面静止、不做景深 |
